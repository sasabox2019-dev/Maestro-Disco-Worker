# prompts — Sistema «Núcleo + Skills + Dientes»

Herramientas para desarrollar software con agentes de IA en cualquier app de chat con acceso a disco.

## Qué hay aquí
- `v2/` — **Sistema v2.0** (actual): núcleo de arranque (123 líneas), worker (100), 12 skills Agent Skills, plantillas (AGENTS.md, ADR, SPEC, verificar.sh, pre-commit), Manual, LEDGER de lecciones e informe final de obra.
- `old/` — v1.1 archivada (el "prompt gigante" original de 3.502 líneas), intacta y etiquetada `v1.1-final`.

## Filosofía
> La IA no es la memoria del proyecto. La IA trabaja SOBRE la memoria del proyecto.

- `v1.1-final` → la época del prompt gigante
- `v2.0` → núcleo corto + skills bajo demanda + verificación mecánica
